This is the first post on my new site. It's a plain Markdown file in `content/blog/`, and everything you see here — headings, code, quotes, tables — comes from ordinary Markdown.

## Why a personal site

A place of my own to write things down, on a site that loads instantly and has no trackers.

> Writing is thinking. To write well is to think clearly.
> — David McCullough

## What a post can contain

Lists work as you'd expect:

- **Bold**, *italic* and `inline code`
- [Links](https://www.getzola.org) — external ones open in a new tab
- Nested lists
  1. one
  2. two

Code blocks get syntax highlighting and a copy button:

```rust
fn main() {
    let greeting = "Hello, world";
    println!("{greeting}!");
}
```

```bash
zola serve --drafts
```
