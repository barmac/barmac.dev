This site is generated by [Zola](https://www.getzola.org), a single program that turns a folder of Markdown files into plain HTML. The whole build takes a few milliseconds.

## Writing a post

Each post is one file in `content/blog/`. The block at the top, between the `+++` lines, holds its title, date, description and tags:

```toml
+++
title = "My new post"
date = 2026-11-09
description = "One sentence that shows up in lists and link previews."

[taxonomies]
tags = ["notes"]
+++
```

Everything below it is ordinary Markdown. Add `draft = true` to keep a post off the live site while you work on it.

## What's built in

- **Search** — Zola writes a search index at build time; press <kbd>⌘</kbd> <kbd>K</kbd> or <kbd>/</kbd>.
- **Tags** — every tag gets its own page, plus a feed.
- **Feed** — subscribe at `/atom.xml`.
- **Light and dark** — follows your system, or pick one with the toggle in the header.
- **Page transitions** — done in CSS alone; browsers without support simply load the next page.
